# 客户营销总控台 V2

这是一个面向 **短视频培训 / 陪跑 / 代运营 / 本地实体客户** 的长期客户运营管理软件。

它不是“一次填表、一次生成结果”的工具，而是把一个客户从第一次了解、深度访谈、整体运营规划、3—5条样板、三次上门培训、作业、视频数据、复盘到 AI 长期讨论全部保存在同一个客户工作空间里。

## V2 主要功能

### 1. 客户总控台
- 所有客户
- 合作类型 / 状态 / 当前阶段
- 下一步动作
- 最近跟进
- 下次培训
- 待完成作业
- 最近视频数据

### 2. 客户长期档案
行业完全自由填写，不使用固定行业下拉。
可长期修改：
- 老板 / 出镜人
- 产品 / 价格 / 利润
- 客户目标
- 当前问题
- 核心优势
- 目标人群
- 竞品
- 账号现状
- 设备
- 执行能力
- 老板经历
- 家庭 / 夫妻 / 孩子
- 其他长期备注

### 3. 第一次客户深度访谈
内置 100+ 个问题，分为：
- 基础经营
- 产品价格利润
- 目标客户
- 竞争对手
- 老板经历
- 失败 / 亏损 / 被坑被骗
- 家庭 / 孩子
- 性格 / 原则 / 口头禅
- 老顾客 / 真实故事
- 行业专业 / 误区 / 观点
- 真实经营可拍场景
- 抖音历史 / 设备 / 执行能力
- 最终目标 / 服务边界

每个问题支持：
- 已问
- 回答
- 标记重要
- 标记可拍视频
- 标记下次追问

还支持添加自定义问题，以及让 AI 根据当前已回答内容推荐下一批问题。

### 4. 详细运营规划
字段拆开长期保存，包括：
- 客户诊断
- 账号定位
- 一句话人设
- 身份 / 性格 / 经历 / 专业 / 地域标签
- 目标客户
- 核心优势
- 当前最大问题
- 昵称
- 头像
- 简介
- 背景图
- 封面风格
- 置顶 3 条
- 主页前 9 条
- 同城方向
- 人设故事方向
- 专业方向
- 产品方向
- 真实顾客方向
- 真实经营方向
- 热点方向
- 老板观点方向
- 当前阶段目标
- 当前不要做什么
- 调整记录

### 5. 内容库
7 个状态：
- 灵感
- 待写
- 待拍
- 已拍
- 待发布
- 已发布
- 已复盘

每条内容保存：
- 选题
- 类型
- 拍摄目的
- 开头钩子
- 完整口播
- 镜头脚本
- 补素材
- 封面
- 发布文案
- 话题
- 拍摄 / 发布日期
- 对应培训
- 复盘
- 下一条怎么复制

### 6. 三次上门培训：标准教案 + 实际记录
可一键从标准教案创建本次培训，再根据客户实际情况修改。

每次培训记录 40+ 项：
- 日期 / 地点 / 目标 / 时长
- 准备拍什么 / 实际拍什么
- 选题 / 文案 / AI 文案
- 手机设置 / 构图 / 人物站位 / 光线 / 收音
- 口播 / 分句 / 补素材 / 镜头
- 现场示范 / 客户实操
- 剪辑 / 节奏 / 字幕 / 音乐 / 补画面
- 封面 / 标题 / 发布 / 定位门店
- 客户学会什么 / 还不会什么
- 现场问题 / 已纠正问题
- 作业 / 验收标准 / 下次重点
- 实际结果
- AI 补充教案

核心逻辑固定：
**定选题 → 写/改文案 → 现场拍 → 边拍边教 → 现场剪 → 客户实操 → 纠错 → 留作业**

3—5 条样板视频直接融合在三次上门里，不单独设置代拍阶段。

### 7. 作业
每条可记录：
- 标题 / 类型
- 布置日期 / 截止日期
- 作业说明
- 客户提交内容 / 提交时间
- 完成状态
- 我的反馈
- 主要问题
- 下次纠正
- 对应培训

### 8. 视频数据
每条视频支持 12 项：
- 播放
- 点赞
- 评论
- 收藏
- 分享
- 主页访问
- 私信
- 问价
- 问地址
- 咨询
- 到店
- 成交

支持 AI 结合最近 5 条做复盘。

### 9. 时间线
长期记录：
- 沟通
- 拍摄
- 培训
- 作业
- 内容
- 数据
- 复盘
- 方向调整

### 10. AI 运营助手
每个客户独立对话。

服务器会自动给 AI 传入当前客户的：
- 核心档案
- 运营规划
- 重要 / 最近访谈
- 最近内容
- 最近培训
- 未完成作业
- 最近视频数据
- 最近时间线

不需要每次从头介绍客户。

快捷任务：
- 整个运营规划
- 下一次执行单
- 3—5 条文案
- 根据访谈梳理人设
- 复盘最近 5 条
- 下一次培训教案

AI 回答可以保存到：
- 客户档案
- 运营规划
- 内容选题
- 完整文案
- 培训计划
- 培训记录
- 作业
- 复盘
- 时间线

### 11. 同城泛流量模板库

内置「城市争议话题（12 类）」「同城藏宝（藏现金 / 藏代金券 / 藏套餐产品）」「街头采访（10 类）」三类模板形式。

模板不做静态成品，点「AI 生成」会结合当前客户真实档案现场生成可直接拍的文案；生成结果可保存回内容库。

### 12. 店内日常拍摄模板库

内置「接客讲产品 / 顾客第一视角 / 消费账单 / 制作交付 / 售后处理 / 开收店日常」6 类模板形式。

同样由 AI 结合当前客户的门店、产品与行业现场生成，生成后可保存回内容库。

## 本地运行

需要 Node.js 20+。

如果只用本地 JSON 文件，不配置数据库也可以直接运行：

```bash
node server.js
```

打开：

```text
http://localhost:3000
```

如果要使用 PostgreSQL：

```bash
npm install
DATABASE_URL=你的数据库连接串 node server.js
```

---

## 环境变量

复制 `.env.example` 里的变量到你的部署平台：

```bash
APP_PASSWORD=你自己的访问密码
DEEPSEEK_API_KEY=你的DeepSeek API Key
DEEPSEEK_MODEL=deepseek-chat
DATABASE_URL=Railway PostgreSQL自动提供的连接串
```

`DEEPSEEK_MODEL` 请填写你的 API 账号实际可用模型。

**不要把真实 API Key 写进前端代码或提交到 GitHub。**

---

## Railway 部署建议

1. 上传本项目到 GitHub。
2. Railway 新建项目并连接 GitHub 仓库。
3. 添加 PostgreSQL 服务。
4. Railway 会给应用注入 `DATABASE_URL`。
5. 设置：
   - `APP_PASSWORD`
   - `DEEPSEEK_API_KEY`
   - `DEEPSEEK_MODEL`
6. 启动命令：
   ```bash
   npm start
   ```
7. 健康检查：
   ```text
   /api/health
   ```

程序在有 `DATABASE_URL` 时自动使用 PostgreSQL；没有数据库时退回 JSON 文件。

## V2.1 保存与上线验收

- 登录页、侧栏和首页显示 V2.1；客户工作空间入口在“新增客户”或客户卡片中。
- 顶部显示保存进度，失败可点击重试；网络恢复后自动重试。未保存时离开页面会提醒。
- 同一页面的保存请求按顺序执行，AI 提问与退出前先完成保存。
- JSON 文件损坏或数据库驱动异常时会报错，不再静默显示空客户列表。健康检查会实际读取存储。
- `npm test` 使用临时文件验证登录保护、保存、重启恢复、导入导出及保存失败重试，不修改线上客户。
- 目前按整个工作台保存数据，请避免多台设备同时编辑；AI 服务仍需有效的 DEEPSEEK_API_KEY。
